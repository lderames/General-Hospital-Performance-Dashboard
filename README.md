# Introduction
📊 This suite of dashboards provides a comprehensive view of healthcare operations, focusing on patient demographics, mortality rate, medical outcomes, financial claims, and overall hospital performance. By integrating key metrics across multiple dimensions, these dashboards empower administrators, healthcare professionals, and financial teams to make data-driven decisions that improve patient care, optimize resources, and ensure financial sustainability.

# Background

**DataSense PH** has launched an exciting **Data Challenge** for aspiring data professionals and enthusiasts, providing a platform to showcase their analytical and visualization skills. Participants are given structured datasets and tasked with developing dashboards that uncover key trends and actionable insights.




# Tools Used
- 📊 Power BI Desktop - Main data visualiztion tool for report creation.
- 📁 Power Query - Data transformation and cleaning layer for reshaping and preparing data.
- 🧠 DAX ( Data Analysis Expression) - Used for calculated measures, dynamic visuals, and conditional logic.
- 📋 Data Modeling - Relationship established among tables to enable filtering and aggregation.
